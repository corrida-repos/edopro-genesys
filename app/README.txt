GENESYS DECK POINTS for EDOPro
==============================

What you get
- A "Genesys" entry in EDOPro's Ban List dropdown. Link and Pendulum monsters show as banned.
  The list updates itself every time you start EDOPro.
- A small window that shows your deck's Genesys points (cap 100). It turns red over the cap,
  lists every card that costs points, and flags Link/Pendulum cards.
  It updates each time you SAVE a deck in EDOPro.

Install
1. Unzip this folder anywhere (your EDOPro folder is fine).
2. Double-click Install.bat. It finds EDOPro by itself, or asks you where it is.
3. Open "Genesys Deck Points" (desktop shortcut). It starts EDOPro and the points window.
4. In Deck Edit, choose "Genesys" in the Ban List dropdown.

If Windows shows "Windows protected your PC", click "More info" then "Run anyway".
The app is not signed; its full source is in addon\src.

Uninstall: double-click Uninstall.bat.

Points come from Konami's official Genesys table (via YGOPRODeck), checked daily:
https://github.com/corrida-repos/edopro-genesys
